# lowbit_comm 0.3.0 Major Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the legacy Python control plane with a typed, compile-once low-bit communication architecture whose normal FullTensor path remains quantized through every cross-rank stage.

**Architecture:** A device-independent Semantic IR is verified and lowered by one compiler pipeline into backend-owned executables. CUDA reuses proven kernels behind the new Backend Protocol; DDP and sharded training live in adapters that own training state. The legacy tree remains an oracle until all mandatory rows in the migration matrix are READY.

**Tech Stack:** Python 3.10+, dataclasses/enums/protocols, pytest, PyTorch distributed, CUDA/C++ extension, NCCL, setuptools/wheel.

## Global Constraints

- Product version is exactly `0.3.0`; release notes say `BREAKING: Major Architecture Refactor`.
- New production code lives under `src/lowbit_comm` and never imports `ccdl_comm`.
- Core never imports Torch, CUDA, Ascend, Backend packages, or adapters.
- `operation`, `output`, `wire`, and `algorithm` remain separate typed dimensions.
- Quantized FullTensor has zero FP collectives in its normal data path.
- ReducedShard never performs a final full all-gather.
- Explicit algorithms are strict; only `auto` may compile-time fallback.
- Workspace leases release only after their completion event is ready.
- No production code is written before its failing test is observed.
- Every task ends with a focused Conventional Commit.
